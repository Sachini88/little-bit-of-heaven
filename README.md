# Little Bit of Heaven

Promotional showcase site for **Little Bit of Heaven** — artisan kiln-fired pottery and indoor plants in Cranbourne, Victoria.

## Live site

After GitHub Pages is enabled, the site is published at:

**https://sachini88.github.io/little-bit-of-heaven/**

## Local preview

Open `index.html` in a browser, or run a simple server:

```bash
npx serve .
```

## Stack

Static HTML, CSS, and JavaScript — no build step required.
